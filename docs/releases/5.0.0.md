# SysPerf 5.0.0 — release record

_25 October 2026. The filled-in `docs/RELEASE_CHECKLIST.md` for this release,
in the completion-report form of UAISES §21._

## Delivery summary

- **Outcome:**
  - SysPerf audited against UAISES v1.0, then fixed and verified. The
    checklist score rose from 66.1% (4.1.0) to 88.2% (5.0.0).
  - The security gate went from FAIL to PASS. Packaging stays UNVERIFIED (see
    risks).
- **Changed files:** 61+ files on branch `uaises-compliance`, in small
  single-purpose commits (`git log v4.1.0..v5.0.0`).
- **Architecture decisions:** DECISIONS.md ADR-003 (Host allowlist), ADR-005
  (polling), ADR-010 (DPAPI), ADR-011 (coverage is not proof), ADR-012
  (hash lock).
- **User-visible behaviour verified:**
  - All 8 tabs of the live 5.0.0 dashboard driven in Chromium: 0 console or
    CSP errors, and no unexpected POSTs.
  - Store-mode Home shows all five optional features off.
  - Supervised restart ran three times; the service was back in under 30 s each time.

## Risks and remaining work

- **Blockers:** none for the scripted install. For the Store, run the
  clean-machine install / upgrade / uninstall test.
- **Unverified claims:**
  - MSIX on a clean machine.
  - A 24-hour `tools/soak.py` run.
  - The real side effect of four controls (standby clear, Explorer watchdog
    trigger, App Control, OneDrive stop). See FEATURE_AUDIT.md.
  - A screen-reader walk-through.
- **Known limitations:**
  - No authentication, so loopback only.
  - Metrics are polled (ADR-005).
  - `app.py` is large.
- **Rollback:**
  - Scripted install: `git switch --detach v4.1.0` in the checkout, then
    restart. State files are compatible.
  - Store: reinstall `SysPerf_4.1.0.0_x64.msix`.
- **Next highest-value step:** the clean-machine MSIX test, which would also
  lift the four lowest checklist rows.
