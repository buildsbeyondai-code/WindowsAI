SysPerf 4.1.0 — quick start
===========================
Easiest: run the graphical installer
  * double-click  SysPerf-Setup-4.1.0.exe   (self-extracting; opens a wizard), OR
  * right-click   install-wizard.ps1  ->  Run with PowerShell
No administrator rights are needed; everything installs under your user profile.

================================================================================
  SysPerf - System Performance Agent 4.1.0
  START HERE
================================================================================

  A read-only performance dashboard and advisor for Windows 11.
  Free and open-source software, Apache License 2.0.


WHAT IT DOES
--------------------------------------------------------------------------------
  Measures how your Windows machine is behaving, compares it against where it
  started and what it is capable of, and tells you what to change to make it
  faster.

  It never changes a setting on your behalf. Every system call it makes is a
  query. Recommendations are text: what was measured, why it matters, and the
  step to take. You decide and you act, so you always know what changed.


INSTALL (about two minutes)
--------------------------------------------------------------------------------
  1. Copy the SysPerf folder to the machine (or unzip SysPerf-2.0.0.zip).

  2. Right-click the Start button and choose "Terminal" or "Windows PowerShell".

  3. Change to the folder, for example:

         cd "$env:USERPROFILE\Downloads\SysPerf"

  4. Run:

         powershell -ExecutionPolicy Bypass -File install.ps1

  5. When it finishes, open:  http://127.0.0.1:5056/

  No administrator rights are needed. If Python is missing the installer offers
  to fetch it. Everything is written to %LOCALAPPDATA%\SysPerf and your own
  Start Menu - no Windows service, no system settings, nothing shared.


FIRST MINUTE
--------------------------------------------------------------------------------
  Live values appear within seconds. Scores and recommendations appear after the
  first full sweep, about a minute in, which is when SysPerf records your
  baseline.

  Everything will read 0% at first. That is correct: progress is measured from
  where YOU started, and you have not changed anything yet. The numbers move as
  you act on the recommendations.


WITHOUT INSTALLING
--------------------------------------------------------------------------------
  For a one-off report on a machine you would rather not install anything on:

         powershell -ExecutionPolicy Bypass -File run.ps1 -Report

  Prints the scorecard and recommendations to the console. Creates a .venv
  folder in this directory and touches nothing else.


UNINSTALL
--------------------------------------------------------------------------------
         powershell -ExecutionPolicy Bypass -File uninstall.ps1

  Add -Purge to delete collected history as well. Because SysPerf never changed
  a Windows setting, there is nothing to revert.

REQUIREMENTS
--------------------------------------------------------------------------------
  Windows 11 (build 22000+). Windows 10 works but is not the test target.
  PowerShell 5.1, which ships with Windows.
  Python 3.9 or later - the installer can fetch it via winget.
  A standard user account. Nothing needs elevation.
  Network access once, to download two Python packages. Offline after that.


PRIVACY
--------------------------------------------------------------------------------
  Nothing leaves the machine. There is no telemetry, no upload, no account, and
  the dashboard loads no third-party scripts - it works with networking off.

  Treat http://127.0.0.1:5056/api/metrics as sensitive: it lists running
  processes, installed drivers and startup entries. That is why the server binds
  to your own machine only. Set "anonymize": true in the config before sharing a
  screenshot.


IF SOMETHING GOES WRONG
--------------------------------------------------------------------------------
  Section 12 of the PDF manual covers the common cases. The two most frequent:

  "Python 3.9 or later is required"
      Install from https://www.python.org/downloads/windows/ ticking
      "Add python.exe to PATH", then open a NEW terminal and re-run install.ps1.

  "Dependency installation failed"
      Usually a corporate proxy. Set it and retry:
          $env:HTTPS_PROXY = 'http://proxy.example.com:8080'

NEW IN 4.0 - AI SELF-EVOLUTION
  A new "AI Self-Evolution" tab. SysPerf can propose and validate improvements
  to its own source code with an AI model, in an isolated sandbox, and keeps
  them as review branches for your approval. Autonomy defaults to "observe"
  (recommend only). Guide: docs\AI_EVOLUTION.md.
  Validate on Windows:  powershell -ExecutionPolicy Bypass -File tools\validate-windows.ps1

NEW IN 2.2.0 - AUTO-IMPROVE
  The dashboard's fourth tab runs an autonomous loop: it scans every 5 minutes,
  and when the score is under 80% it works out WHY (short-term spike, usage,
  long-term regression, or an unreachable target), fixes what is safely fixable,
  then measures whether that helped and learns from it.

  It only acts when fixes.enabled is true in the config, and it only ever runs
  reversible, non-disruptive fixes. Choose "observe" in the tab to see the full
  diagnosis and plan without anything being executed. Manual: chapter 14.

NEW IN 3.2.0 - CONTAINER DEPLOYMENT
  Optional, for WSL 2 + Docker users: the dashboard runs in an unprivileged,
  read-only container and reaches Windows only through an allowlisted,
  logged host-exec broker.

         bash container/install-container.sh

  See container/README.md. The native Windows install is unchanged.
