SysPerf 5.3.0 - START HERE
================================================================================
A performance dashboard for Windows 11. It measures your PC from Windows' own
counters, learns this PC's normal, and shows what is slowing it down and why.
Free and open-source software (Apache License 2.0).
https://github.com/buildsbeyondai-code/WindowsAI


INSTALL (about two minutes, no administrator rights)
--------------------------------------------------------------------------------
  1. If you received a .zip: right-click it -> Properties -> tick "Unblock"
     (if shown) -> OK. Then right-click -> Extract All.

  2. In the extracted folder, double-click   Install SysPerf.cmd
     A small setup wizard opens. Click Install.
     (Or: right-click install-wizard.ps1 -> Run with PowerShell.)

  3. When it finishes, click "Open dashboard", or open  http://127.0.0.1:5056/

  Needs Python 3.10 or later. If it is missing, the installer offers to fetch
  it with winget. It also downloads two small Python packages once, so an
  internet connection is needed during install.

  Everything goes into %LOCALAPPDATA%\SysPerf and your own Start Menu. No
  Windows service is created and nothing is installed for other users.

  Command-line alternative:
      powershell -ExecutionPolicy Bypass -File install.ps1


FIRST MINUTE
--------------------------------------------------------------------------------
  Live values appear within seconds. Scores appear after the first full sample,
  about a minute in, which is when SysPerf records this PC's baseline. Many
  rows read 0% progress at first: progress is measured from where this PC
  started.


WHAT IT CAN CHANGE ON YOUR PC
--------------------------------------------------------------------------------
  SysPerf can make a few reversible changes: flush DNS, trim idle apps'
  memory, restart a stuck Explorer, and quit tray apps you have allowed (it
  asks first for each app). Each has its own switch: tray auto-quit and the
  Explorer watchdog on the App Control tab, OneDrive control on the
  Auto-Improve tab, and automatic fixes under Autonomy on the AI
  Self-Evolution tab (it starts at Observe, which only recommends).

  To make SysPerf only measure and recommend, set  "fixes": {"enabled": false}
  in %LOCALAPPDATA%\SysPerf\sysperf.config.json and restart it.


PRIVACY
--------------------------------------------------------------------------------
  No account, no ads, no telemetry. The dashboard answers only on this PC
  (127.0.0.1) and refuses requests from other websites. Once a day it reads
  public release pages to check component versions; it sends nothing about
  your PC. The optional AI features are off until you add your own AI key.

  The dashboard shows process, driver and device names. Check screenshots
  before you share them.


UNINSTALL
--------------------------------------------------------------------------------
      powershell -ExecutionPolicy Bypass -File uninstall.ps1
  Add -Purge to delete the collected history as well.


WITHOUT INSTALLING
--------------------------------------------------------------------------------
  For a one-off text report:
      powershell -ExecutionPolicy Bypass -File run.ps1 -Report


IF SOMETHING GOES WRONG
--------------------------------------------------------------------------------
  "Python 3.10 or later is required"
      Install Python from https://www.python.org/downloads/windows/ and tick
      "Add python.exe to PATH". Open a new window and run the installer again.

  "Dependency installation failed"
      Check the internet connection. Behind a company proxy, set it first:
          $env:HTTPS_PROXY = 'http://proxy.example.com:8080'

  The dashboard does not open
      Open http://127.0.0.1:5056/ in a browser. If nothing answers, run
      %LOCALAPPDATA%\SysPerf\sysperf.cmd to see the error.

  More help: docs\SysPerf-User-Manual.html (open in any browser).
