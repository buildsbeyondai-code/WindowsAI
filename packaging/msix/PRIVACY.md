# SysPerf privacy policy

*Effective 25 October 2026*

SysPerf is a performance monitor that runs entirely on your PC.

## What it collects
Performance measurements of this PC: CPU, memory, disk, network, battery,
running processes and their resource use, driver and software versions, and
Wi-Fi details (network name, signal, channel). It also records the fixes it ran
and their measured effect.

## Where it goes
Nowhere. Everything is stored in SysPerf's own folder on this PC. The dashboard
is served only on 127.0.0.1 (this computer) and can't be reached from the
network. SysPerf has no account, no analytics and no advertising, and it sends
no telemetry.

## The one exception: AI self-evolution (off by default)
If you turn on AI self-evolution and enter your own AI provider key, SysPerf
sends that provider (for example Anthropic) excerpts of SysPerf's own source code
and summary performance figures, so it can propose code improvements. That
provider's privacy policy then applies. Personal files are never sent. Turn the
feature off, or delete the key, to stop it.

## Changes SysPerf makes to your PC
Only the ones you turn on (Home > Optional features), or the fixes you click
yourself. Each one says what it does and how to undo it.

## Deleting your data
Uninstall SysPerf. Windows removes its data folder with it.
